# Wahida Naqshbandy — Portfolio Landing Page

A responsive personal portfolio landing page built with **HTML5, CSS3 and Vanilla JavaScript**.

## Features

- Semantic HTML structure
- Responsive navigation with a mobile hamburger menu
- Dark / light theme toggle (saved with localStorage)
- Project category filters
- Project details modal (closes with the close button, backdrop, or Escape key)
- Contact form validation with inline error messages
- Responsive layouts using Flexbox, CSS Grid and media queries
- Hover effects, transitions and reduced-motion support

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.

No npm installation or build step is required.

## Before publishing

Personalize the sample content:

- Replace `hello@example.com` with your real public contact email.
- Update project descriptions and tags to match your actual work.
- Add your real GitHub, LinkedIn and other profile links if you want them in the navigation/footer.
- Check every text detail before sharing the site as your portfolio.

## Contact form note

The form currently performs front-end validation and displays a confirmation message. It does **not** send messages to an inbox. To receive real submissions, connect a form backend/service such as Formspree or your own server.

## Deploy with GitHub Pages

1. Create a **public** GitHub repository.
2. Upload all project files while keeping the folder structure.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown in the Pages section.
